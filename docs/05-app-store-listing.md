## Description
The Invictus Team app is the team's home base: training, resources, events and the Leaderboard
in one place.

Leaderboard
- Tap once to log a membership (1 point) or a $150+ order (2 points).
- See this week's standings and all-time totals, updated live as teammates log sales.
- Get an alert when a teammate makes a sale, if you want one.
- Undo a tap within 15 minutes, or fix your count for the week.

Resources
- Team PDFs, audio trainings, videos and links, ready to open or share.

Events
- What's coming up and where.

Profiles
- Meet the team's leaders, and share a profile with someone you're working with through a
  private link that expires after 7 days.

The app is for members of the Invictus team. Pulse Board members sign in with the email and
password they already use. New members create an account with the team code from their upline.

## App Privacy (the "nutrition label")
Tracking: **No**, the app does not track.

Data collected, all **linked to the user**, all used only for **App Functionality**:
- Contact Info → Name, Email Address
- User Content → Photos or Videos (profile photo), Other User Content (sales logged)
- Identifiers → User ID, Device ID (push token for sale alerts)

Not collected: location, contacts, health, financial info, browsing history, usage data,
diagnostics, purchases.
